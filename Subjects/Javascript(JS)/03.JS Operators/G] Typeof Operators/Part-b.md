9.Create three variables:
- `price = 99.99`
- `message = "Welcome"`
- `isActive = false`  
Print the type of each variable with a clear message.

*Answer:*

```js
let price = 99.99;
console.log("Type of variable 'price' is ",typeof(price));

let message = "Welcome";
console.log("Type of variable 'message' is ",typeof(message))

let isActive = false;
console.log("Type of variable 'isActive' is ",typeof(isActive))
```
