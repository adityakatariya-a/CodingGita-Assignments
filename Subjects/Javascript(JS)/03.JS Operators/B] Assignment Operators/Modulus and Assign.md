### 6. Modulus and Assign `%=`

1. Number 47 is divided by 6. Store only the remainder using `%=`.

**Answer:**

```js
let number = 47;
number %= 6;
console.log(number)
```

---

2. Counter is at 23. Keep only the remainder when divided by 12 using `%=`. 

**Answer:**

```js
let number = 23;
number %= 12;
console.log(number)
```
