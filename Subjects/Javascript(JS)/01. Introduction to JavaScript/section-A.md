
# Section A: Short Answer Questions

**Q1. What is JavaScript?**  
JavaScript is a high-level, dynamically typed programming language used to create interactive websites and applications.

**Q2. Who created JavaScript and in which year?**  
JavaScript was created by Brendan Eich at Netscape in 1995.

**Q3. What was the original name of JavaScript?**  
JavaScript was originally named **Mocha**, then renamed **LiveScript**, and finally **JavaScript**.

**Q4. Is JavaScript the same as Java? Give one major difference.**  
No, JavaScript and Java are different languages. JavaScript is dynamically typed, while Java is statically typed.

**Q5. What does it mean when we say JavaScript is a high-level programming language?**  
It means JavaScript uses simple, human-readable instructions. Programmers do not need to directly manage memory or hardware instructions.

**Q6. Is JavaScript a compiled language or an interpreted language? Explain briefly.**  
JavaScript is an interpreted language. A JavaScript engine reads and executes the code while the program runs.

**Q7. Name the JavaScript engines used by the following browsers.**  

| Browser | JavaScript Engine |
|---|---|
| Google Chrome | V8 |
| Mozilla Firefox | SpiderMonkey |
| Apple Safari | JavaScriptCore |

**Q8. What is Dynamic Typing in JavaScript?**  
Dynamic typing means JavaScript automatically identifies a value’s data type while the program runs. A variable can also hold different data types at different times.

**Q9. What is the main difference between a static website and a dynamic website?**  
A static website mainly displays fixed content after loading. A dynamic website can respond to users and change its content or behavior.

**Q10. Name the three pillars of Front-end Web Development and write one line about each.**  
- **HTML:** Creates the structure and content of a web page.  
- **CSS:** Adds style, colours, and layout to the web page.  
- **JavaScript:** Adds behaviour, actions, and interactivity to the web page.  

**Q11. What is the difference between Frontend and Backend?**  
Frontend is everything the user sees and interacts with in the browser. Backend handles logic, data processing, storage, and security behind the scenes.

**Q12. What is Node.js?**  
Node.js is a JavaScript runtime environment that allows JavaScript to run outside the browser. It is commonly used to create servers and backend applications.

**Q13. Explain ECMAScript. What is its relation with JavaScript?**  
ECMAScript is a standard or rulebook that defines how JavaScript should work. JavaScript is a programming language that follows the ECMAScript standard.
