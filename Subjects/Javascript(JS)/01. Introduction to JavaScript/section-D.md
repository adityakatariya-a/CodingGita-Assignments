**Q14. Differentiate between a static website and a dynamic website. Give one real-world example of each.**

| Static Website | Dynamic Website |
|---|---|
| Displays fixed content, such as text, images, and links, after loading. | Can respond to user actions and change content while the user interacts with it. |
| Example: A basic personal portfolio website. | Example: YouTube, where users can play videos, like, comment, and search. |

**Q15. Explain any two features of JavaScript that make it suitable for creating interactive web pages.**

1. **Event-driven:** JavaScript can respond to events such as button clicks, key presses, form submissions, and page loading.  
2. **Dynamic typing:** JavaScript automatically identifies data types while the program runs, making it easy to work with different types of data.

**Q17. What is the difference between writing JavaScript code inside an HTML file and in an external `.js` file? Mention two advantages of using an external JavaScript file.**

JavaScript written inside a `<script>` tag is placed directly in the HTML file. An external JavaScript file keeps the code in a separate file with the `.js` extension and is linked to the HTML file.

Advantages of an external file:

1. It keeps HTML and JavaScript code separate and organised.  
2. The same JavaScript file can be reused on multiple web pages.  

**Q18. Explain the difference between Frontend and Backend using the restaurant analogy in your own words.**

In the restaurant analogy, the **customer** is the user, and the **frontend** is what the customer sees and interacts with. The **waiter** acts like the server, taking requests between the frontend and backend. The **backend** works behind the scenes, while the **database** is like the chef that stores and provides the required data.

**Q19. Why should a beginner learn JavaScript? Write at least 4 points.**

1. JavaScript makes websites interactive and dynamic.  
2. It can be used for both frontend and backend development.  
3. It can run in web browsers as well as on servers using Node.js.  
4. It can be used to build mobile apps, desktop apps, games, and dashboards.  
5. Beginners can quickly see the results of their code.  
6. JavaScript has a large developer community.
